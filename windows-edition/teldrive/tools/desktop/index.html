Configuración

Puedes crear una base PostgreSQL local incluida o conectar tu servidor existente. Detén Teldrive antes de guardar. Tus datos se conservan en el perfil de Windows.

PostgreSQL necesita el runtime de Microsoft Visual C++ en este equipo. Puedes descargar e iniciar el instalador oficial desde aquí; Windows mostrará sus permisos y condiciones.
