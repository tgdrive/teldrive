# Traducciones

Diez idiomas incluidos sin conexión. catalog.json usa el texto original como clave; {0}, {1}… son valores interpolados y no se traducen. No se traducen nombres de archivos, rutas, claves, configuraciones ni contenido del usuario. Español es el idioma predeterminado. Las traducciones iniciales son automáticas y admiten revisión en este archivo.
