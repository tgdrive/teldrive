---
title: Files and folders
description: Manage files and folders in the Teldrive web UI.
---

The **Files** page supports list/grid views, multi-selection, uploads, copy/move, rename, sharing, downloads, and Trash.

## Selection

Single-click selects. Open folders explicitly or by double-clicking so selection does not trigger navigation.

Bulk actions support copy, move, and trash. Rename/share are single-item actions.

## Copy, move, rename

Use the selection action bar or clipboard-style copy/cut/paste controls. Renaming changes catalog metadata; file payloads are not re-uploaded.

## Download

Download selected files or copy authenticated download links. Large files support HTTP range requests for seeking/streaming.

## Trash

Delete moves items to **Trash**. From Trash, restore or permanently purge them.

Purge is destructive.
