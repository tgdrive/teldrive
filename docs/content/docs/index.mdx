## Choose your path

### I just want it running

Follow the **Quick start**. It uses the published container image and PostgreSQL and explains every required value before you start Teldrive.

You do **not** need to understand Go, Telegram MTProto, River jobs, or the internal database schema to operate a normal installation.

### I want to understand what I am deploying

Read **How Teldrive works** after the quick start. It explains which data is stored in PostgreSQL, which data is stored in Telegram, why Teldrive needs a Telegram API application, and what the security keys protect.

### I run production infrastructure

Go directly to **Production deployment**, **Security**, and **Database** after the quick start. Those pages cover the settings that matter when Teldrive is exposed to the internet.

## What you need

A normal deployment needs:

- a machine or VM capable of running Teldrive;
- PostgreSQL;
- outbound internet access to Telegram;
- a Telegram account;
- a Telegram API application ID and hash;
- persistent PostgreSQL storage;
- two private Teldrive secrets: a signing key and a data key.

For public deployments, you should also use a domain name, HTTPS, and a reverse proxy.

> **Important:** Telegram applies API limits and anti-abuse controls. Teldrive does not remove those limits. Treat Telegram as a remote storage backend with its own rules and rate limits, not as an unlimited anonymous object store.

## Configuration model

Teldrive accepts the same settings from three places. Later sources override earlier ones:

```text
defaults
  ↓
config.toml / config.yaml
  ↓
TELDRIVE_* environment variables
  ↓
explicit command-line flags
```

This means beginners can use a single configuration file, while container and orchestration users can use environment variables without maintaining a generated config file.

## Useful server commands

```bash
# Start the server
teldrive run

# "serve" is an alias for "run"
teldrive serve

# Validate configuration and initialize dependencies, then exit
teldrive check

# Show build information
teldrive version
```

The rest of this documentation uses `teldrive run` consistently.
