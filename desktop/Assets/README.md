# Icono de Teldrive Desktop

`Teldrive.png` es el avión sobre nubes proporcionado por el usuario, convertido a un PNG con fondo transparente mediante la herramienta integrada `image_gen`, el 12 de octubre de 2026. La imagen original del usuario se conserva fuera del proyecto. `Teldrive.ico` contiene versiones de 16, 24, 32, 48, 64, 128 y 256 píxeles para Windows, convertidas del PNG sin cambiar el diseño. La aplicación, la ventana y la bandeja comparten este icono.

Prompt utilizado:

> Use case: background-extraction. Edit target: attached original Windows application icon. Remove ONLY the black background outside the blue circular badge and all black border pixels, replacing them with genuine alpha transparency. Preserve the complete blue circular badge, white paper airplane, blue clouds, light trails, original gradients, artwork, proportions, placement, and colors. Keep the circular outline clean with antialiased transparent edges, no black matte halo. Do not redesign the logo, add text, or change the contents within the blue disk. Output a square PNG with actual transparent background, centered icon filling almost the square, with a very small transparent margin.
